# AI Career Advisor 🚀

An AI-powered Career Advisor that analyzes resumes and provides personalized career recommendations using Google Gemini, LangChain, and LangGraph.

## Features

- Upload Resume (PDF)
- Resume Skill Analysis
- AI Career Recommendations
- GitHub Profile Analysis
- Personalized Learning Roadmap
- Streamlit Web Interface

## Tech Stack

- Python
- Streamlit
- LangChain
- LangGraph
- Google Gemini API
- PyPDF2

## Installation

Clone the repository

```bash
git clone https://github.com/deekshith2301/AI-Career-Advisor.git
```

Install dependencies

```bash
pip install -r requirements.txt
```

Create a `.env` file

```env
GOOGLE_API_KEY=YOUR_API_KEY
```

Run

```bash
streamlit run app.py
```
